# Presentation direction

Reference: the Graft README supplied by Adrian, with a large product wordmark, cinematic artwork, generous spacing and compact rectangular badges.

StockPilot uses its own subject and accent rather than reusing another project's logo. The hero is AI-generated conceptual brand artwork, not a product screenshot or evidence of results. Existing application screenshots retain their provenance captions.

GitHub controls page typography and layout. Native Markdown and HTML are used without custom CSS, fixed badge heights or fabricated awards. The hero is static; essential information is repeated in accessible text. Changes are limited to documentation and assets.
